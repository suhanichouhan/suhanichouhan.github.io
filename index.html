Databases and performance

Database Performance Benchmarking

MySQL, MongoDB, Cassandra, Redis, Neo4j | Docker, Python | 1M records

Problem
Compare how 5 database systems perform on the same queries as data grows from 250K to 1M records.
Approach
Designed 4 benchmark queries and ran each 30 times per dataset size. Deployed Neo4j, Redis and Cassandra in Docker and loaded data with Python (pyodbc, pymongo, py2neo, redis, cassandra-driver).
Result
Cassandra was fastest on key-based lookups (0.057s at 250K). MongoDB was fastest on pattern and multi-key queries (under 1s at 1M). Redis was slowest because of client-side scan_iter overhead.
